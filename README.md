# Adventure Works Executive Dashboard

## Project Overview
Developed an interactive Power BI dashboard to analyze business
performance, revenue, profit, orders, and product returns.

## Dashboard Preview

![Adventure Works Dashboard](Adventure%20Works%20Executive%20Dashboard.PNG)

## Key Performance Indicators
- Total Profit: $10.5M
- Total Revenue: $24.9M
- Total Orders: 25.2K
- Return Rate: 2.2%

## Key Features
- Monthly Revenue Analysis
- Order Analysis by Category
- Top 10 Products Analysis
- Monthly Orders and Returns
- Revenue and Profit Tracking
- Product Return Rate Analysis

## Tools Used
- Power BI
- Data Visualization
- Business Intelligence
- KPI Analysis
- Sales Analytics

## Business Objective
To analyze business performance and provide actionable insights
through interactive visualizations and key performance indicators.
